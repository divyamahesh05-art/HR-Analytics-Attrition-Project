# HR Analytics: Employee Attrition & Retention

## Objective
Analyse employee attrition, retention and department-wise trends to find which departments lose the most employees and why.

## Tools
- Microsoft Excel (data cleaning, PivotTables, dashboard)
- Power BI Desktop (interactive report, DAX)

## Dataset
560 synthetic employee records across 7 departments (Sales, Customer Support, IT, HR, Finance, Operations, Marketing). Fields: Department, JobRole, Gender, Age, HireDate, ExitDate, Status, Salary, PerformanceRating, SatisfactionScore, Overtime, ExitReason.

## Data Cleaning
Checked duplicates, blanks, spelling consistency, data types and value ranges. ExitDate blanks are valid (active employees).

## Key Metrics
- Attrition % = Leavers / Total Employees
- Retention % = 1 - Attrition %
